# 06 UI 参考清单

不要寻找一个网站照搬。建议分别参考“交互结构、视觉氛围、信息密度、发布方式”，再组合成自己的语言。

## 第一优先：技能树与游戏 UX

### Game UX Research — Skill Tree

https://www.viettuong.design/game-ux-research

重点看：Skyrim、Path of Exile、Cyberpunk 2077、Diablo IV 在层级、前置关系、复杂度和可读性上的差异。适合决定技能树如何组织，不建议照搬其美术。

### GameRes：技能树 UI 设计分析

https://www.gameres.com/913976.html

重点看：中文语境下的技能树类型、信息架构与常见问题。适合在开发前建立判断标准。

### Figma Community：RPG UI System

https://www.figma.com/community/file/1615676025515807988/game-ui-dark-fantasy-rpg

重点看：任务、能力、物品详情等页面如何保持组件一致。只借鉴组件系统，不采用暗黑奇幻装饰。

## 第二优先：视觉细节

### ArtStation — Skill Tree Game UI

https://www.artstation.com/artwork/BXWBDA

重点看：技能节点、连线、图标和选中状态。ArtStation 适合寻找高完成度游戏 UI，但要注意很多作品偏展示图，不一定适合真实网页。

### Dribbble — Game Dashboard / Skill Tree

https://dribbble.com/search/game-skill-tree

重点看：卡片构图、色彩和局部微交互。不要直接照搬，因为 Dribbble 作品常缺少真实内容密度和移动端状态。

### Interface In Game

https://interfaceingame.com/

重点看：按游戏和界面类别查找真实游戏截图，特别关注地图、任务、技能与日志页面。这比只看概念图更适合验证可用性。

## 第三优先：网页排版与科研可信度

### Land-book

https://land-book.com/

搜索 `personal portfolio`、`dashboard`、`dark`，参考网页首屏、导航和内容节奏。

### Awwwards

https://www.awwwards.com/

用于寻找大胆的互动叙事与视觉语言。只选一两个可控灵感，不要把大量滚动特效带入第一版。

### Mobbin

https://mobbin.com/

用于参考成熟产品的导航、筛选、详情抽屉和移动端信息布局。部分内容需要账号。

## 工具与发布参考

### Figma Community

https://www.figma.com/community

搜索关键词：`skill tree`、`game dashboard`、`space dashboard`、`quest log`、`dark design system`。

### GitHub Pages 官方入口

https://pages.github.com/

查看个人站点与项目站点的仓库命名方式。

### GitHub Pages 官方文档

https://docs.github.com/en/pages

发布、Actions、自定义域名和故障排查以官方文档为准。

## 参考时的记录模板

每看到一个喜欢的页面，只记录以下五项：

```text
来源链接：
我喜欢的部分：
它解决了什么问题：
是否适合手机：
我会如何改造成射电科研语境：
```

建议最终只保留 6–10 张核心参考图，分成：布局、节点、任务卡片、色彩、移动端五组。避免收集过多导致方向摇摆。
