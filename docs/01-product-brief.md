# 01 产品与范围

## 一句话定义

一个以射电天文学为世界观的个人科研 RPG 网站：访客可以看到“角色状态—当前任务—研究地图—技能树—成长记录”，作者可以通过编辑本地数据文件长期维护。

## Phase 0 已确认品牌

- 网站名称：`xiii`
- 公开身份：研究豹（一只在做科研的海豹）
- 英文辅助描述：`a seal doing research`
- 首页主文案：`hello astro`
- 视觉参考：NASA × ESO
- 视觉解释：深空影像、任务编号、观测参数、科研档案与望远镜控制台；不直接使用官方 Logo，也不暗示官方隶属关系。

## 目标用户

### 主要用户：未来的自己

- 快速确认当前主线和下一步行动。
- 回顾自己已经掌握的技能和完成的里程碑。
- 在课题尚未完全确定时，保留方向调整空间。

### 次要用户：导师、同学与潜在合作者

- 迅速了解研究兴趣与能力范围。
- 看到公开成果和可复现项目。
- 通过网站入口前往 GitHub、论文或联系方式。

### 可扩展用户：其他研究生

- fork 仓库。
- 替换个人资料和任务数据。
- 使用同一套科研游戏化框架。

## 核心体验

访客进入网站后，30 秒内应能回答：

1. 你是谁、研究什么？
2. 你目前位于科研地图的哪里？
3. 当前主线任务是什么？
4. 已经解锁了哪些技能？
5. 最近完成了什么？

## 第一版范围（MVP）

- 首页 / 角色面板
- 研究世界地图
- 技能树
- 主线与支线任务日志
- 成就与更新日志
- 关于我与外部链接
- 响应式布局、基础无障碍、深色模式

## 暂不做

- 登录与多人系统
- 网站内编辑内容
- 云数据库与实时同步
- 排行榜、连续打卡惩罚
- 大型 3D 场景
- 自动抓取私人科研记录

## 成功标准

- 新访客无需说明即可理解网站的核心概念。
- 作者能在 5 分钟内修改一个任务或技能状态。
- 手机和电脑都能完整浏览。
- 页面刷新后不会出现 GitHub Pages 路由 404。
- Lighthouse 的可访问性、最佳实践与 SEO 目标均为 90 分以上。

## 公开边界

所有内容在提交前分为三类：

- `public`：可公开的技能、已发表成果、通用学习计划。
- `summary`：只发布概述，不放原始数据或内部结论。
- `private`：未发表结果、内部会议内容、账号密钥、服务器信息，绝不进入仓库。
